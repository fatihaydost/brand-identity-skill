PASS if the reply is one intake message that asks only what blocks the work: for logo, fonts and colours whether each is new, a refresh, kept as is or not needed; how many directions (offering 3 as the default); whether there is a website or existing files; and which languages the brand writes in. Questions are grouped and answerable in one reply, defaults are offered, and it does not ask again what the user already said (a bakery).
FAIL if it asks a long questionnaire (more than about eight questions), spreads questions over several turns, asks nothing and presents finished identity sets, or asks what kind of business it is.
